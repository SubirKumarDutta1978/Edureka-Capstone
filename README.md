# Edureka Capstone

Generative AI and ML capstone: a WinForms (C# / .NET) app to query enterprise documents using RAG and AI agents.

## Run
1. Open `Edureka Capstone.sln` in Visual Studio 2022 (with the ".NET desktop development" workload).
2. Press F5.

## Structure
- `Forms/` - WinForms UI
- `Services/` - ingestion, chunking, embeddings, retrieval, RAG
- `Agents/` - planner / retriever / reasoner / validator agents
- `Models/` - DTOs
- `Configuration/` - strongly typed settings
- `Data/Uploads/` - uploaded documents
